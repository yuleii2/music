## 3. 数据模型、schema 与迁移

### 3.1 可信练习会话

`PracticeSession` / `PracticeRecordStore` 当前内部 schema 为 **3**，兼容文件名仍是 `practice-records-v1.bin`。字段包括：

- 稳定会话 ID、开始/结束时间、练习类型、和弦序列；
- BPM、拍号、切换方式、计划/实际时长；
- 尝试、成功、失败、最佳连续；
- legacy 标记与旧完成次数；
- 来源进行 ID，以及是否保留来源进行的逐步节奏。

迁移策略：

- schema 1 读取为 `legacy=true`，保留旧完成数和可证实历史，但可信尝试/成功/失败均为 0，不能形成 100% 成功率。
- schema 2 读取现有可信字段，来源进行字段使用安全默认值。
- 首次读取 schema 1/2 后，经现有原子二进制存储层写回 schema 3；写入采用临时文件替换并维护 `.bak` 回退。
- 会话按稳定 ID 保存；相同 ID 不会被新增为第二条会话。

### 3.2 方向性逐次尝试

`TransitionAttemptStore` schema 为 **1**，文件为 `transition-attempts-v1.bin`。每条记录包含：尝试 ID、会话 ID、时间、from/to 和弦、from/to 指法 ID、BPM、拍号、切换方式、成功布尔值、可用时的确认偏移和练习模式。

尝试按稳定 ID upsert；写入重试、Activity 重建或重复恢复同一备份不会增加第二条相同尝试。`C → G` 和 `G → C` 的 key 不同，始终分开统计。

### 3.3 学习档案与备份

- `LearningProfile` schema **1**：引导完成标记、水平、最多两个目标、每日分钟数、体验模式、创建/更新时间。
- 完整备份 schema **1**：最多 32 个 ZIP 条目，单条最多 5 MiB、解压总量最多 20 MiB，拒绝路径穿越、未知/缺失分区、超版本和 checksum 不一致。

## 4. 练习结果与熟练度口径

- 总尝试数 = 当前会话持久化逐次尝试条数。
- 成功数 = `success=true` 条数；失败数 = `success=false` 条数。
- 当前连续次数按时间顺序扫描：成功时 `+1`，失败时立即变为 `0`。
- 最佳连续次数是扫描过程中出现过的最大当前连续值；后续失败不会降低它。
- 成功率 = `成功数 / 总尝试数`；没有可信尝试时为无值并显示“尚无数据”，不显示 100%。
- 每个方向最多取最近 20 次，少于 5 次只显示“数据不足”。稳定 BPM 是同一 BPM 至少 5 次且成功率至少 80% 的最高 BPM。
- 熟练度分数 = 成功率 × 60 + `min(稳定 BPM, 100) / 100 × 20` + `min(当前连续, 5) / 5 × 10` + 时效分；7 天内 10 分、30 天内 5 分、否则 0 分，四舍五入并限制到 0–100。
- 等级阈值：`<35` 待练习，`35–59` 正在建立，`60–79` 基本稳定，`80–100` 熟练。
- 难度建议取最近最多 20 次：少于 10 次不建议；成功率至少 90% 且有两次稳定可比会话时升 5 BPM；至少 75% 保持；至少 50% 降 5 BPM；否则降 10 BPM，范围限制 40–240 BPM。

## 5. 动态首页与模式差异

今日 planner 完全离线且确定性运行：先过滤到真实存在、符合模式横按/品位约束的和弦，再结合学习目标、可信方向性 mastery、最近练习时间、收藏和熟悉指法安排薄弱复习、基础巩固和新内容。初学者新内容顺序为 C、G、Am、Em、D、A、Dm、E；专业模式可使用更完整资料。少于 5 个方向样本时没有弱项任务，也不会显示“最薄弱切换”。

“继续上次练习”直接恢复并开始：模式、和弦、BPM、拍号、切换方式、时长、横按、最高品位、来源进行 ID 和原进行节奏；“调整”才进入设置页。弹唱准备使用真实保存进行、70 BPM、120 秒并保留每一步拍数；速度挑战只在至少有两个熟悉和弦时提供。

新手模式默认：精简/折叠高级乐理，只突出推荐指法，不显示技术标签，50 BPM、60 秒、禁用横按、最高 5 品、低信息密度且高级练习设置折叠。

专业模式默认：展开高级乐理和技术标签，显示全部指法，80 BPM、120 秒、允许横按、最高 24 品、紧凑信息密度且高级设置展开。模式通过 CompositionLocal 进入页面，修改设置后当前 Compose 层即时重组。

## 6. 完整备份、排除项与冲突处理

ZIP 包含 10 个 JSON 分区：

1. 界面、练习和非秘密 AI 配置；
2. 学习档案；
3. 收藏；
4. 带真实时间戳的最近历史；
5. 自定义指法；
6. 熟悉指法 ID；
7. 和弦进行；
8. 进行草稿；
9. 练习会话；
10. 方向性逐次尝试。

设置分区中的 AI 内容只包括启用状态、服务名、Base URL、模型、温度和超时。**不包含 API Key、Keystore 密文/别名、AI 结果缓存或其他密钥材料**。恢复设置调用 `AiSettingsStore.save(..., null)`，因此不会从备份写入或清除设备当前 API Key。

合并策略：收藏取并集；历史按 symbol 合并并采用较新时间，最终最多 12 项；相同 ID 且内容不同的自定义指法/进行生成“恢复副本”；练习会话和尝试按稳定 ID 去重，冲突时保留本地版本。相同备份重复合并时记录会被跳过，统计不会翻倍。覆盖模式整体替换已校验分区；任一异常或取消都会用恢复前快照回滚。合并模式可选择是否恢复设置。
